# AI-Powered DevOps Error Analyzer

A Flask-based REST API that uses Google Gemini AI to analyze error logs and suggest possible causes and fixes. Built as a hands-on DevOps project covering the full development lifecycle — from coding to CI/CD deployment.

## Features

- **REST API** built with Flask, including dynamic routing and proper error handling
- **AI Integration** — analyzes error logs using Google Gemini AI and returns likely causes and fixes
- **Retry Logic** — automatically retries failed AI calls up to 3 times to handle temporary API issues
- **Structured Logging** — all requests, warnings, and errors are logged to `app.log`
- **Automated Testing** — 5 unit tests using pytest covering all major routes
- **Dockerized** — fully containerized for consistent deployment across environments
- **CI Pipeline** — Jenkins pipeline that automatically installs dependencies and runs tests on every push

## Tech Stack

- **Backend:** Python, Flask
- **AI:** Google Gemini API
- **Testing:** pytest
- **Containerization:** Docker
- **CI/CD:** Jenkins
- **Version Control:** Git, GitHub

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/` | Health check message |
| GET | `/health` | Returns app health status |
| GET | `/greet/<name>` | Returns a greeting message |
| POST | `/analyze-error` | Accepts an error log and returns AI-generated analysis |

## Setup & Installation

1. Clone the repository:
   ```
   git clone https://github.com/Tanvi1907/ai-devops-project.git
   cd ai-devops-project
   ```

2. Create a virtual environment and install dependencies:
   ```
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. Add your Gemini API key:
   - Copy `.env.example` to `.env`
   - Add your API key from [Google AI Studio](https://aistudio.google.com/apikey)

4. Run the application:
   ```
   python app.py
   ```

## Running with Docker

```
docker build -t ai-devops-app .
docker run -p 5000:5000 --env-file .env ai-devops-app
```

## Running Tests

```
python -m pytest test_app.py -v
```

## Example Usage

**Request:**
```
POST /analyze-error
Content-Type: application/json

{
  "error_log": "ConnectionError: Unable to connect to database at port 5432"
}
```

**Response:**
```json
{
  "original_error": "ConnectionError: Unable to connect to database at port 5432",
  "ai_analysis": "Likely cause and fix generated by AI..."
}
```
